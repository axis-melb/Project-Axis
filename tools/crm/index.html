§01 WHY THIS EXISTS / 初衷
THE PROBLEM / 痛点
I find that managing 50-100 policyholders doesn't require a heavy CRM, and Excel lacks automatic reminders. Plus, I don't want my client data on someone else's cloud. / 管理几十个客户并不需要庞大的系统，且 Excel 缺乏自动提醒。我不希望资料上传云端。

× 传统的 CRM 昂贵且复杂
× Excel 需手动翻查日期
× 数据储存在第三方不安全

THE SOLUTION / 解决方案

→ 纯 HTML 链接，本地优先，隐私受控
→ 30天自动“飘红”提醒，准时联系客户
→ 自填比例计算佣金，财务状况一眼知
→ 导出 JSON 备份，真正拥有你的数据

§02 FEATURES / 功能
F.001
ANNIVERSARY ALERT

保单周年日前30天，客户条目将自动显示为红色，确保不漏过交费提醒。

F.002
COMMISSION CALC

录入保单年缴及年限，配合自填佣金率，实时计算您的预期业务收益。

F.003
CLIENT NOTES

自由记录客户偏好、家庭详情或跟进备注，所有内容仅保留在您手中。

SECURITY & BACKUP

All data is stored in your browser's localStorage. Recommended to export JSON backup weekly. / 数据保留在本地浏览器，建议每周导出 JSON 备份。
